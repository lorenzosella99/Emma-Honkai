# Emma Honkai · Chat 🌟

> Plataforma de chat com personagens e pessoas do universo Honkai — com bot, moedas, missões e painel admin.

## ✨ Funcionalidades

- **Chat com personagens** · Bot responde com pensamento, ação e fala quando estiver offline
- **Sistema de moedas** · Pensamentos custam moedas · Ganhe jogando missões
- **Missões** · Missões especiais para novos usuários · Admin cria missões customizadas
- **Painel Admin** · Gerenciar personagens, custos, banimentos e missões
- **Sistema de ban** · 3 dias de ban com aviso · Personagem/usuário banido sai temporariamente
- **Código de acesso** · Necessário para se cadastrar · Peça no Discord

## 🚀 Como Usar

1. Acesse o site via GitHub Pages
2. Digite o código de acesso (peça no Discord)
3. Crie sua conta
4. Comece a conversar!

## 🔑 Acesso

O cadastro exige um código de acesso válido, fornecido pelos canais oficiais do projeto. Códigos administrativos não são publicados neste repositório. Nunca compartilhe códigos privados, senhas ou tokens.
